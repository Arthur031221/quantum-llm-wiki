# 量子位元（Qubit）

量子位元是量子資訊的基本單位，也就是量子版的位元。一般認為 qubit 這個詞是 Benjamin Schumacher 創的，他在 1995 年論文的致謝裡寫到，這個詞是和 William Wootters 聊天時開玩笑想出來的。

## 實體上是什麼

任何有兩個能階的量子系統都可以當量子位元，例如：

- 電子的自旋：向上、向下兩個狀態。
- 單一光子的偏振：水平、垂直兩個方向。

實際的量子電腦常用超導電路或離子阱來做量子位元（見[量子電腦](quantum-computer.md)）。

## 和古典位元比較

| | 古典位元 | 量子位元 |
|---|---|---|
| 可能的狀態 | 0 或 1 | $\alpha\lvert 0\rangle + \beta\lvert 1\rangle$，$\alpha$、$\beta$ 是複數 |
| 讀取（測量）時 | 狀態不受影響 | 疊加被破壞，得到 0 或 1 |
| n 個一起描述 | n 個 0 或 1 | 需要 $2^n$ 個複數 |

一般的寫法是

$$|\psi⟩ = \alpha|0⟩ + \beta|1⟩, \qquad |\alpha|^2 + |\beta|^2 = 1$$

$|0⟩$、$|1⟩$ 叫做計算基底（computational basis），$\alpha$、$\beta$ 叫機率振幅（probability amplitude）。$\alpha$ 或 $\beta$ 有一個是 0 時，量子位元就跟古典位元一樣；兩個都不是 0 時，量子位元處在[疊加](superposition-and-measurement.md)。通俗說法是「同時是 0 也是 1」，但正式的意思是兩個振幅都不為零。

## 布洛赫球（Bloch sphere）

扣掉歸一化條件和沒有物理意義的整體相位，一個量子位元的純態剩下兩個角度 $\theta$、$\varphi$，可以畫成球面上的一點：

$$\alpha = \cos\frac{\theta}{2}, \qquad \beta = e^{i\varphi}\sin\frac{\theta}{2}$$

古典位元只能在北極（$|0⟩$）或南極（$|1⟩$）；量子位元可以在球面上任何一點。例如 $(|0⟩+|1⟩)/\sqrt2$ 在赤道上。和環境互動、產生雜訊之後，狀態會跑到球的內部，變成混合態。

## 多個量子位元

每多一個量子位元，狀態空間的維度就加倍。兩個量子位元的基底是 $|00⟩, |01⟩, |10⟩, |11⟩$，四維；n 個量子位元是 $2^n$ 維。要用古典電腦記下 100 個量子位元的狀態，需要存 $2^{100}$ 個數，這也是古典電腦很難模擬量子電腦的原因。

多個量子位元還可以[糾纏](entanglement.md)，這是古典位元沒有的性質。

## 對量子位元能做的事

- 用[量子邏輯閘](quantum-gates.md)改變狀態（可逆）。
- [測量](superposition-and-measurement.md)（不可逆，會破壞相干性）。
- 初始化成已知狀態，通常是 $|0⟩$。
