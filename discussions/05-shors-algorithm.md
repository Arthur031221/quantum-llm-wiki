# 討論：Shor's algorithm

來源：raw/05-shors-algorithm.md（英文維基百科，rev 1384103273）

## 1. 這篇在講什麼

Shor 演算法用量子電腦在多項式時間內分解整數，會威脅 RSA 等公鑰加密。條目講了演算法的兩個部分、實際實驗的規模，以及距離實用還有多遠。

## 2. 初學者需要的重點

- 1994 年由 Peter Shor 提出，用來找整數的質因數（導言）。
- 量子電腦上的執行時間是 log n 的多項式；已知最好的古典演算法（一般數域篩法）是次指數時間（導言）。
- 如果有夠大、夠穩定的量子電腦，就能破解 RSA 和 Diffie–Hellman；這也推動了後量子密碼學（Feasibility and implications）。
- 演算法分兩部分：古典部分把分解問題轉成「找週期（order）」，量子部分用量子相位估計找出週期（Algorithm）。
- 實驗現況：2001 年 IBM 用 7 個量子位元的 NMR 系統分解 15；2012 年分解了 21；這些實驗都事先知道答案，不算完整實作（Physical implementation）。
- 要贏過古典電腦，可能需要數百萬個量子位元，因為量子錯誤更正的成本很高（導言）。
