# 討論Shor's algorithm

來源是raw/05-shors-algorithm.md，英文維基百科版本1384103273。

## 1. 這篇在講什麼

Shor演算法用量子電腦在多項式時間內分解整數，會威脅RSA這類公鑰加密，條目講了演算法的兩個部分、目前實驗做到多大，以及離實用還有多遠。

## 2. 初學者需要的重點

- Peter Shor在1994年提出，用來找整數的質因數，出自導言
- 在量子電腦上的執行時間是log n的多項式，擴展性最好的古典演算法是一般數域篩法，需要次指數時間，同樣出自導言
- 只要有夠大、夠穩定的量子電腦，就能破解RSA和Diffie-Hellman，這也帶動了後量子密碼學，出自Feasibility and implications
- 演算法分兩部分，古典部分把分解問題轉成找週期，量子部分用量子相位估計把週期找出來，出自Algorithm
- 2001年IBM用7個量子位元的NMR系統分解了15，2012年分解了21，可是這些實驗都事先知道答案，不算完整實作，出自Physical implementation
- 要贏過古典電腦可能需要數百萬個量子位元，因為量子錯誤更正的成本很高，出自導言
