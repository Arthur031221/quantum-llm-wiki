# 討論：Quantum decoherence

來源：raw/06-quantum-decoherence.md（英文維基百科，rev 1384689551）

## 1. 這篇在講什麼

退相干是量子系統跟環境互動、失去量子相干性的過程。條目從概念、數學、時間尺度講到防止退相干的方法，最後一段和量子計算直接相關。

## 2. 初學者需要的重點

- 退相干：系統的量子資訊流失到環境中，量子行為慢慢變成古典行為（導言、Concept）。
- 封閉系統的純態會一直保持純態；系統不完全隔離時，相干性會分享給環境（Concept）。
- 巨觀物體跟環境的交互作用極多，退相干極快，所以日常生活看不到量子行為（Timescales）。
- 防止退相干的方法：隔離環境（真空、低溫、電磁屏蔽、屏蔽宇宙射線）、量子錯誤更正、動態解耦（Prevention）。
- 量子錯誤更正把一個邏輯量子位元的資訊分散存到多個實體量子位元，例如 Shor code 用 9 個、Steane code 用 7 個（Quantum error correction）。
