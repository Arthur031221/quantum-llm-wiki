# 討論Quantum decoherence

來源是raw/06-quantum-decoherence.md，英文維基百科版本1384689551。

## 1. 這篇在講什麼

退相干是量子系統跟環境互動、失去量子相干性的過程，條目從概念、數學、時間尺度一路講到怎麼防止退相干，最後那部分和量子計算直接相關。

## 2. 初學者需要的重點

- 系統的量子資訊流失到環境裡，量子行為就慢慢變成古典行為，這就是退相干，出自導言和Concept
- 封閉系統的純態會一直維持純態，系統沒有完全隔離時，相干性會分享給環境，出自Concept
- 巨觀物體跟環境的交互作用極多，退相干極快，所以日常生活看不到量子行為，出自Timescales
- 防止退相干有幾種做法，包括隔離環境，例如真空、低溫、電磁屏蔽和屏蔽宇宙射線，再來是量子錯誤更正和動態解耦，出自Prevention
- 量子錯誤更正把一個邏輯量子位元的資訊分散存到好幾個實體量子位元上，Shor code用9個，Steane code用7個，出自Quantum error correction

## 4. 疑點與決定

- 密度矩陣、Kraus算子和半群這些數學細節全部不寫
- 原文有個類比很適合初學者，相干性沒有消失，是混進了環境的自由度，就像摩擦把能量變成熱，可以拿來用
- 01篇提到至少要300萬個實體量子位元、花5個月才能分解2,048位元的整數，所以這頁的sources要同時列06和01
